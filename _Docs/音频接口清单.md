# 音频接口清单

> 全部通过 `RoomAudioVfx` 组件配置，**留空即不播，不会报错**。
> 玩法代码零改动 —— 所有音效都是订阅 `RoomEvents` 触发的。

## 怎么用

1. 建场后 Hierarchy 里找 `=== Room2D === ▸ AudioVfx`（建场自动创建）
2. 把 AudioClip 拖进对应槽位
3. 完成，不需要任何其他接线

---

## 一 · 背景音乐（本次新增）

按回合阶段自动切换，带交叉淡化。

| 槽位 | 阶段 | 建议 |
|---|---|---|
| `Bgm Intro` | 开场介绍（门关闭、不可操作） | 氛围铺垫，可留空 |
| **`Bgm Searching`** | **搜索阶段** | **玩家听最久的一首，最重要** |
| `Bgm Collapse` | 终局全塌陷 | 应该更紧张、更快 |
| `Bgm Settlement` | 结算与穿越 | 可留空则静音 |

**参数**：

| 参数 | 默认 | 说明 |
|---|---|---|
| `Music Volume` | 0.55 | BGM 独立音量，与音效分开 |
| `Music Fade Time` | 0.8 | 交叉淡化时长。0 = 硬切。搜索→塌陷建议短一点（0.3~0.6），突然变紧张更有冲击力 |
| `Music End Pitch Up` | 1.08 | 搜索末段随倒计时提速。只在最后 35% 生效 |

**实现细节**（供排查用）：
- BGM 用独立 `AudioSource`（自动创建名为 `MusicSource` 的子物体），与音效分开才能各自调音量，也避免 `PlayOneShot` 的音调抖动影响音乐
- 同一首曲子不重启 —— 否则每次阶段变化音乐都会从头播
- 淡化用 `unscaledDeltaTime`：命中定格会把 `timeScale` 压到 0.12，音乐淡化不该跟着变慢
- 淡化期间不动 `pitch`，避免与末段提速打架

## 二 · 肘击

| 槽位 | 触发 | 说明 |
|---|---|---|
| **`Sfx Elbow Swing`** | 挥肘瞬间，**不论是否命中** | 本次新增。没有它挥空毫无声音反馈，玩家会以为技能没触发 |
| `Sfx Elbow Hit` | 命中时 | 与破风音叠加播放 |
| `Sfx Item Knocked Out` | 把对手道具打掉时 | |
| `Vfx Elbow Impact` | 命中时的粒子 | 现有程序化冲击环（`ImpactRing`）作为占位，填了这个可在 `PlayerActionFx` 关掉 `Spawn Impact Ring` |

**时序**：按键 → `Sfx Elbow Swing`（立即）→ `elbowWindup` 0.12 秒 → 判定 → 命中则 `Sfx Elbow Hit`

破风音的音调抖动设为 0.12（比其他音效大），连续挥肘才不会像复读机。

## 三 · 搜索

| 槽位 | 触发 | 说明 |
|---|---|---|
| `Sfx Search Start` | 开始搜索 | |
| **`Sfx Search Complete`** | 读条走满 | 本次新增。**即使容器已空也播** —— 玩家需要知道「搜完了」，否则不清楚该不该继续按着不动 |
| `Sfx Search Interrupt` | 被打断（被肘击 / 离开范围 / 脚下地板塌） | |
| `Sfx Item Collected` | 拿到道具 | |
| `Sfx Item Rare` | 拿到稀有道具 | 填了会优先于 `Sfx Item Collected` |
| `Vfx Item Pickup` | 拿到道具的粒子 | |

**注意**：`Sfx Search Complete` 与 `Sfx Item Collected` 是两个不同时机。空柜子搜完只播前者。

搜索是 2.4 秒的读条，如果要循环的「翻找中」音效，目前**没有专门通道** —— 需要的话告我，可以加一个 `searchLoop` 的 AudioSource（和警报循环音一样的做法）。

## 四 · 掉进空洞

| 槽位 | 触发 |
|---|---|
| `Sfx Pitfall` | 玩家踩空掉进洞里 |
| `Sfx Tile Cracking` | 地板开裂预警 |
| `Sfx Tile Collapsed` | 地板塌陷 |
| `Sfx Final Collapse` | 终局全塌开始 |
| `Vfx Tile Cracking` | 开裂的碎屑与红光 |
| `Vfx Tile Collapse` | 塌陷的坠落尘土 |

**`Sfx Tile Cracking` 建议一定要有** —— 这是玩家躲开塌陷的关键听觉线索，纯靠视觉（地板染红）在混战中很容易漏掉。

爬回来目前**没有音效通道**。`RoomEvents.OnPlayerRecovered` 事件是有的，需要的话可以加。

## 五 · 其他现有槽位

| 槽位 | 触发 |
|---|---|
| `Sfx Jump` | 起跳 |
| `Sfx Land` | 落地 |
| `Sfx Land Heavy` | 从 `heavyLandHeight`（默认 1.2 米）以上落下 |
| `Vfx Land Dust` | 重落地的尘土 |
| `Alarm Loop` | 警报循环音（AudioSource，不是 Clip）|

**警报循环音**是一个 `AudioSource` 而非 `AudioClip` —— 因为它需要持续播放并实时调音调音量。搜索阶段自动播放，随倒计时推进：

```
Alarm Pitch Range   0.85 → 1.35
Alarm Volume Range  0.25 → 0.85
```

## 附：音量层级建议

目前只有两个总音量（`sfxVolume` 0.9 / `musicVolume` 0.55），没有接入设置菜单。

如果之后要做音量设置，建议的结构：

```
Master
├─ Music      ← musicSource
├─ SFX        ← sfxSource（一次性音效）
└─ Ambient    ← alarmLoop + 将来的吊扇/环境音
```

现在是直接改 `AudioSource.volume`，接 AudioMixer 会更规范但需要改动 `RoomAudioVfx`。要做的话告我。
