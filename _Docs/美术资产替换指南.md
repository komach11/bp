# 美术资产替换指南

工程已拆分到「**换 prefab 即换外观**」的颗粒度。所有美术槽位集中在一个资产里，
代码不需要改动。

---

## 一、核心设计：碰撞与视觉分离

这是整套机制的基础，理解它就不会踩坑。

```
Box_文件柜                 ← 碰撞盒：规整 Cube，尺寸 = 逻辑尺寸
│  · BoxCollider           玩家跳跃落点、平台高度全靠它
│  · MeshRenderer.enabled = false   （填了美术模型后自动关闭渲染）
│
└── ArtPivot               ← 反向缩放层，抵消碰撞盒的非等比 scale
    └── Art                ← 美术模型：只负责好看，自带 Collider 已被清除
```

**这样带来的保证**：

| 换模型后 | 是否会变 |
|---|---|
| 跳跃能不能上桌 | 不变（碰撞盒尺寸不动） |
| 桌面容器的高度 | 不变（`PlatformInfo.topY` 仍等于逻辑尺寸） |
| `CharacterController.stepOffset` 爬台阶 | 不变 |
| 只有外观 | ✅ 变 |

所以你可以放心替换，不会把手感调坏。

## 二、在哪里替换

`Assets/BugParty2D/Config/RoomArtConfig2D.asset`

首次执行 `BugParty2D ▸ Build Room Scene` 会自动创建它并挂到 `RoomConfig2D` 上。

`containerOverrides` 已预填全部 14 个容器名，直接往对应项拖模型：


留空的会退到 `containerDefault`，`containerDefault` 也空就用彩色方块。

## 三、每个槽位的选项

```
prefab       美术模型。留空 = 用程序生成的占位方块
fitToSize    勾选：按包围盒等比缩放到逻辑尺寸（默认）
             取消：保持模型原始大小
scaleMul     额外缩放微调，默认 1
yawOffset    绕 Y 轴旋转（度）。模型朝向不是 +Z 时用它纠正
yOffset      垂直微调。脚底不在 y=0 时补偿
```

`fitToSize` 会自动处理两个常见问题，**不需要你手动调**：
- 模型不是米制单位（Kenney 的桌子有 7.3 单位宽）
- 轴心不在几何中心（Kenney 多数模型轴心在角落）

### 导入步骤

1. Unity 会自动导入 `.obj`。在 Project 窗口选中模型

4. 执行 `BugParty2D ▸ Build Room Scene` 重新建场

## 五、必须注意的三件事

### 1. 会议桌是 11×4 米，不是真实尺寸

这是为「桌上追逐」玩法故意放大的。拿一张真桌子 `fitToSize` 会等比缩放到
高度对齐，桌面宽度不够；强行拉伸则严重变形。

**建议**：`desk` 槽位取消勾选 `fitToSize`，用 `scaleMul` 手动放大到合适程度，
接受桌面由多张桌子视觉拼接的效果。或者接受占位方块作为大桌，只替换其他家具。

### 2. 故障风由代码叠加，不要买「自带故障感」的模型

`BugAmbience` 在运行时做悬浮、抖动、青蓝闪烁。所以 `floatingProp` 和其他槽位
都应该填**正常的家具模型**。自带发光/glitch 的模型会与 `glitchColor` 叠加过曝。

本次已改进 `BugAmbience`：现在会收集**全部子 Renderer** 并逐个混合底色，
所以多 mesh 的美术模型也能正常闪烁（之前只改第一个 Renderer，换模型后
闪烁会几乎看不见）。

### 3. 高亮与染红已自动重定向

`SearchContainer.highlightRenderer` 和 `FloorTile.tileRenderer` 在美术模式下
会自动指向真正可见的 Renderer，而不是被隐藏的碰撞盒。搜索高亮、塌陷预警染红
都正常工作，不需要手动配。

## 六、混元3D 提示词（用于补缺口）

不要写发光、扫描线、霓虹、glitch —— 那些由代码做。

```
low-poly [物件名], flat-shaded faceted surfaces, single palette texture,
no PBR maps, hard edges, neutral grey-blue color scheme,
axis-aligned front-facing, resting flat on ground plane,
clean topology, under 500 triangles,
isolated single object on plain background, no scene, no floor
```

物件名替换示例：

| 用途 | `[物件名]` |
|---|---|
| 饮水机 | `bottled water dispenser, blue jug on top` |
| 投影仪箱 | `hard equipment case with latches` |
| 会议桌 | `long conference table, rectangular top` |
| 服务器机柜 | `server rack cabinet, ventilation slits` |

若确实想要模型层面的破损感（代码叠加不出来的那种），追加：

```
..., one corner missing as if corrupted,
jagged pixelated broken edge, partially dissolved into cubic voxel fragments
```
