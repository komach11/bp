# 肘击特效接入说明

给美术/特效同学：肘击有 **四个时机** 可挂特效，每个时机都有独立槽位。

---

## 一 · 两条通道，选哪个

肘击特效有两个入口，**用途不同、可以同时用**。

### 通道 A：`ElbowVfxHook`（挂在每个玩家身上）

**选中任意 Player_红/蓝/黄/绿 → Inspector 里的 `Elbow Vfx Hook`**

适合：需要**跟随角色**或**朝向正确**的特效。

- 会跟着角色转身移动（拳套发光、挥动拖尾）
- 命中特效自动朝向「攻击者 → 受击者」，锥形冲击波不会朝错
- **四个玩家各有一份** → 可以给红方配红色拳风、蓝方配蓝色

### 通道 B：`RoomAudioVfx`（场景里唯一一个）

**Hierarchy 里找 `=== Room2D === ▸ AudioVfx`**

适合：**留在原地**的一次性特效（地面裂痕、爆散碎片）。

- 纯世界坐标，不跟随角色
- 全场共用一套，四个玩家表现相同

**建议**：先用通道 A 试，够用就不必碰 B。

---

## 二 · 四个时机与对应槽位

### ① 蓄力 `windupVfx`

按下肘击键的瞬间，持续 **0.12 秒**（`RoomConfig.elbowWindup`）。

- 挂在 **HandAnchor**（手部挂点），跟随角色
- **挥出时自动销毁** —— 特效不需要自带生命周期，做成循环的即可
- 适合：拳套发光、能量汇聚、蓄力粒子

> 这 0.12 秒原先画面毫无变化，按键手感像掉帧。有了它按下去就有反应。

### ② 挥出 `swingVfx`

手臂真正挥动的瞬间，**不论是否命中**。

- 默认挂在 **ElbowOrigin**，朝向角色正面
- `swingFollowsActor` 勾选=跟着转身（拖尾类），取消=留在原地（爆发类）
- 适合：挥动残影、破风弧线、刀光

> **这是「挥空也能看到」的关键。** 原先挥空只有音效，玩家会以为技能没触发。

### ③ 命中 `hitVfx`

打到人的瞬间，生成在**受击者**身上。

- `hitHeight` 控制高度（默认 0.9 米）
- `hitFaceAttackDir` 勾选 → 朝向攻击方向（**锥形冲击波必须勾**）
  取消 → 保持 Prefab 原始朝向（球形爆炸、向上喷的粒子）
- **不挂父级** —— 受击者会被击退，特效跟着走反而削弱打击感
- 适合：撞击火花、冲击波、星星

### ④ 被击中 `getHitVfx`

**自己**被打到时生成在自己身上，跟着被击退一起动。

- 与 ③ 的区别：③ 由攻击者触发，④ 由受害者触发
- 所以可以给不同角色配不同受击反应
- 适合：眩晕星星、头顶冒圈

## 三 · 通用参数

| 参数 | 说明 |
|---|---|
| `lifetime` | 自动销毁时间（默认 2 秒）。**若 ParticleSystem 已设 Stop Action = Destroy，这里填 0** |
| `scaleMul` | 批量缩放，不必改 Prefab |
| `tintByTeamColor` | 用队伍色染色。会改 `ParticleSystem.startColor` 与材质的 `_Color`/`_BaseColor`/`_TintColor`/`_EmissionColor` |
| `windupAnchor` | 蓄力挂点，留空用 HandAnchor |
| `swingAnchor` | 挥出挂点，留空用 ElbowOrigin |

## 四 · 已有的程序化表现（不需要资源）

这三个**已经在生效**，可以与你的特效叠加，也可以关掉：

| 表现 | 在哪调 |
|---|---|
| **冲击环** 20 片方片水平铺开 | `PlayerActionFx.spawnImpactRing`（取消勾选即关闭）、`impactColor`、`impactRingRadius` |
| **命中定格** 时间放慢到 0.12 倍 | `ElbowAbility.hitStopDuration`（0.055，**0.04~0.07 比较自然，超过 0.1 会明显卡顿**） |
| **屏幕抖动** 按命中人数递增 | 代码里 0.16 起，`ElbowAbility.Resolve` |

若你的特效已经足够，建议**关掉冲击环**（`spawnImpactRing` 取消），避免视觉过载。

## 五 · 音效槽位

在 `AudioVfx` 上：

| 槽位 | 时机 |
|---|---|
| `sfxElbowWindup` | 蓄力起手 |
| `sfxElbowSwing` | 挥出（挥空也播） |
| `sfxElbowHit` | 命中 |

## 六 · 排查表

| 现象 | 原因 |
|---|---|
| 特效完全不出现 | 槽位没填；或 Prefab 里 ParticleSystem 的 `Play On Awake` 没勾 |
| 特效出现但立刻消失 | `lifetime` 太短，或 Prefab 自带的 Duration 太短 |
| 特效朝向乱 | 命中特效勾 `hitFaceAttackDir`；挥出特效检查 Prefab 的正面是否朝 +Z |
| 特效不跟随角色 | 挥出特效勾 `swingFollowsActor`；蓄力与被击中特效本来就跟随 |
| 蓄力特效一直不消失 | 它由「挥出」销毁。若角色中途被打断（`Cancel`），组件禁用时也会清掉 |
| 特效被角色挡住 | 2D 俯视下 y 太低会被角色遮住，调高 `hitHeight` |
| 染色没效果 | 粒子颜色在 `ParticleSystem.main.startColor`，改材质无效 —— 勾 `tintByTeamColor` 会两边都设 |

## 七 · 事件接口（程序侧）

若要写自己的特效脚本，订阅这些事件即可，**不必改玩法代码**：

```csharp
RoomEvents.OnElbowWindup += (attacker) => { };            // 蓄力开始
RoomEvents.OnElbowSwing  += (attacker) => { };            // 挥出（不论是否命中）
RoomEvents.OnElbowHit    += (attacker, victim) => { };    // 命中
```

**注意时序**：`OnElbowWindup` → 等 `elbowWindup` 秒 → `OnElbowSwing` → 同帧内 `OnElbowHit`（每个受害者一次，锥形范围内可能多人）。
